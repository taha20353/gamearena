# GameArena

A responsive gaming and esports landing page built with HTML, CSS, and Bootstrap.

**[Live Demo](https://taha20353.github.io/gamearena/)** · **[GitHub Repository](https://github.com/taha20353/gamearena)**

## Features

- Gaming hero section with calls to action
- Latest games showcase
- Gaming services and community sections
- Team member profiles
- Contact section and form layout
- Responsive navigation with a collapsible mobile menu

## Built With

- HTML5 and CSS3
- Bootstrap 5.3.3
- Font Awesome 7.0.1
- Google Fonts: Chakra Petch and Days One
- JavaScript for closing the mobile menu after selecting a link

## Run Locally

```bash
git clone https://github.com/taha20353/gamearena.git
cd gamearena
```

Open `index.html` in your browser, or serve the folder with your editor's local server.
No installation or build step is required. An internet connection is needed for the CDN-hosted styles, fonts, icons, and Bootstrap JavaScript.
